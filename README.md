# BodyMetrics

Современное Android-приложение на Jetpack Compose для отслеживания веса, параметров тела и достижения персональных целей.

## Основные возможности

- **Учёт параметров тела**: фиксация веса, роста, обхватов (грудь, талия, бёдра, бицепс, бедро, шея) и заметок.
- **Динамический расчёт ИМТ**: автоматическое определение индекса массы тела и категории по классификации ВОЗ.
- **Интерактивные графики**: визуализация динамики веса и любых замеров с гибкой фильтрацией (30 дней, 3 месяца, 1 год, всё время, выбор конкретного месяца или произвольного диапазона дат через календарь).
- **Прогноз достижения цели**: умный расчёт темпа изменения веса и предполагаемой даты достижения целевого веса.
- **Компактная резервная копия (JSON v1)**:
  - Экспорт в единый чистый JSON-файл без пустых разделов.
  - Дедупликация при импорте с сохранением более актуальных данных.
  - Окно сводки перед применением изменений.
- **Импорт из Xiaomi Mi Fitness**:
  - Потоковое чтение официального ZIP-архива без загрузки тяжелых файлов в память.
  - Автоматическое извлечение истории взвешиваний и роста из профиля.
  - Пропуск строк без веса и значений $\le 0$.
- **Экспорт и импорт в CSV**: совместимость с Microsoft Excel (UTF-8 с BOM) и Google Таблицами, резервное копирование на Google Диск.

## Стек технологий

- **Язык**: Kotlin
- **UI**: Jetpack Compose, Material 3
- **Архитектура**: MVVM (Model-View-ViewModel), Kotlin Coroutines & StateFlow
- **База данных**: Room (SQLite)
- **Сборка**: Gradle (Kotlin DSL), Android Gradle Plugin 9.x
- **CI/CD**: GitHub Actions (автоматическая сборка APK)

## Сборка проекта

Сборка отладочного APK локально:
```bash
gradle assembleDebug
```

Готовый APK появится в каталоге:
`app/build/outputs/apk/debug/app-debug.apk`
